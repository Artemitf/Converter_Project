# Converter Project

Проект представляет собой приложение на языке Python, предназначенное для автоматизации конвертации валют, получения актуальных курсов и обработки валютных данных.

---

## Описание проекта

Данный сервис разработан для решения задач, связанных с мониторингом курсов валют и выполнением расчетов по актуальному обменному курсу. Приложение взаимодействует с внешними REST API, запрашивает текущие данные, обрабатывает их и предоставляет пользователю удобный интерфейс для работы с финансовой информацией.

Основная цель проекта - обеспечить надежный и точный механизм пересчета сумм из одной денежной единицы в другую с возможностью сохранения результатов и гибкой настройки параметров запроса.

---

## Основной функционал

Конвертация денежных средств между различными валютами по текущему рыночному курсу.

Получение и обновление списка поддерживаемых валют и актуальных котировок в режиме реального времени.

Обработка ошибок при отсутствии сетевого подключения или передаче некорректных символьных кодов валют.

Кэширование и сохранение данных для уменьшения количества повторных сетевых запросов.

Логирование операций и сохранение истории выполненных конвертаций.

---

## Архитектура и используемые технологии

Язык программирования: Python 3.x

Модуль requests: отправка HTTP-запросов к API курсов валют и обработка ответов.

Модуль json: парсинг, структурирование и хранение конфигурационных файлов и ответов API.

Встроенные модули Python (datetime, os, sys): обработка временных меток, работа с файловой системой и консольным выводом.

---

## Требования к окружению

Для корректной работы приложения требуется установленный интерпретатор Python версии 3.8 или выше, а также менеджер пакетов pip.
